# Results index: what each file is and which script generated it

All results are **frozen**. Scripts are under `cnn_benchmark/` and paths below are relative to that folder. Values are mean ± sample SD over 3 seeds unless stated otherwise. None of these scripts trains anything, except `train_ablation.py`, which must not be re-run.

## main/: the A/B/C negative-composition ablation (frozen, Apple MPS)

| File | Content | Generated by |
|---|---|---|
| `abc_summary.csv` | **Headline table:** per condition, mean and SD of pooled tile AUROC / PR-AUC, Saratov recall @20% area, area to 50% Saratov recall, Natanz / Fordow first-hit area | `external_data/paper_summary.py` (from `provenance/run_records/runs/`) |
| `facility_metrics.csv` | The same metrics, one row per condition × seed | `external_data/paper_summary.py` |
| `vlm_comparison.csv` | CNN C vs the single-pass VLM on the facility metrics (same footprint rule) | `external_data/paper_summary.py` (VLM: `src/evaluate_scores.py` → `outputs/evaluations/vlm_single_pass__footprint_parent/`) |
| `abc_tables/` | Full frozen tables: T1 checkpoint selection, T2 tile discrimination, T3 recall at budgets, T4 area for recall targets, T5 per-facility first hits, AOI reversals, long-format data, seed ranges, training curves, `results_tables.md` | `external_data/aggregate_ablation.py` |

Per-run inputs (training and evaluation): `external_data/train_ablation.py` and `external_data/evaluate_ablation.py`. Run records (configs, metrics, scores; no checkpoints): `../provenance/run_records/runs/`.
